# AI Travel Assistant Chatbot

Professional Next.js App Router version of the AI travel assistant dashboard.

## Structure

- `src/app` contains route files, layout, metadata, and not-found UI.
- `src/features` contains business feature modules for dashboard, maps, travel, and translation.
- `src/components` contains reusable shared layout components.
- `src/styles` contains global Tailwind and theme styles.

## Scripts

- `npm run dev` starts the development server.
- `npm run build` creates a production build.
- `npm run start` serves the production build.

Run `` to install the dependencies.

Run `npm run dev` to start the development server.
